# Dual N-Back

A free, browser-based cognitive training app for practicing working memory and attention.

[Start training](https://dualnbackapp.com/trainer/) · [Visit the website](https://dualnbackapp.com/) · [Install the PWA](https://dualnbackapp.com/dual-n-back-app/)

## Features

- Position, audio, and dual training modes
- Progress and settings saved locally in the browser
- Installable PWA for desktop and mobile
- Core training remains available offline after the first successful load
- No account required for core training

## About the project

Dual N-Back is a web application designed for short, repeatable training sessions. It includes learning resources and a trainer that works across modern desktop and mobile browsers.
